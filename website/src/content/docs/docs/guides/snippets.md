---
title: Code snippets
description: Copy any request as runnable code.
---

Open the snippet dialog with the **</>** button next to **Send**, or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>.

The snippet is built from the request as it would be sent right now, with variables resolved against the current environment and auth applied.

| Language | Library |
|---|---|
| Shell | cURL |
| JavaScript | fetch |
| JavaScript | axios |
| Python | requests |
| C# | HttpClient |
| Go | net/http |
| Ruby | Net::HTTP |

:::caution
Because variables are resolved, a snippet contains real tokens and passwords. Check it before pasting it anywhere public.
:::
